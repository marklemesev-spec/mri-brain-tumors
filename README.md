Cистема для детекции и точной локализации опухолей головного мозга (глиома, менингиома, аденома гипофиза) по монохромным срезам МРТ.

## Архитектура решения

* **Входной фильтр Gatekeeper (MobileNetV3-Small)**: Отсекает посторонние фотографии, бытовые изображения и зашумленные сканы (точность 99.9%).
* **Диагностический классификатор (ResNet-50)**: Определяет класс патологии среди 4 категорий: «Глиома», «Менингиома», «Гипофиз», «Опухоли нет» (Macro F1 = 0.9424).
* **Мультимасштабный Grad-CAM++**: Формирует карту внимания с объединением градиентных откликов глубоких сверточных слоев (`layer3` и `layer4`).
* **Анатомическое зонирование (`detect_mri_slice_orientation`)**: Распознает ориентацию среза (аксиальный, корональный, сагиттальный) и исключает физиологические ложноположительные зоны — глазницы, зрительные нервы, решетчатые/клиновидные пазухи и основание черепа.
* **Двухкомпонентное слияние глиомы (`Composite Lesion Fusion`)**: Выполняет замыкание кольцевидных стенок ядром $11 \times 11$ и связывает кистозный гипоинтенсивный компонент со светлым контрастным узлом в единый контур.

## Состав репозитория

* **`test_ai.ipynb`** — демонстрационный ноутбук для экспресс-инференса и проверки интерфейса Gradio.
* **`full_code_mri_ai.ipynb`** — полный воспроизводимый пайплайн (pHash-дедупликация, фильтрация шума, обучение Gatekeeper, каскадный пайплайн).
* **`requirements.txt`** — список необходимых зависимостей.
* **`assets/`** — скриншоты работающего прототипа и результатов оконтуривания.

## Формат выходных данных

При инференсе система формирует:
1. Визуализацию с наложенной маской патологии и bounding box.
2. Вероятностное распределение по всем классам.
3. Врачебную разметку в формате JSON (координаты полигонов и рамок).
